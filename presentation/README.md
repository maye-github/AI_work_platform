# presentation/ — 演示材料

> 这个目录**不属于平台引擎**。引擎的「不含业务」约束只作用于
> `plat/`・`.claude/`・`templates/`（实测 0 处业务词）。
> 演示材料必然引用 R60 的成果物，所以单独放在这里。

| 文件 | 用途 |
|---|---|
| `demo.html` | **可以直接演示**的幻灯片。双击用浏览器打开即可，不依赖网络与任何库 |
| `AI全链路软件工程平台_演示稿.md` | 逐页讲稿，可粘进 PowerPoint 的分页备注 |

## 怎么用 demo.html

| 操作 | 效果 |
|---|---|
| `→` `Space` `PageDown` | 下一页（也可以点右半屏） |
| `←` `PageUp` | 上一页（点左半屏） |
| `F` | 全屏 |
| `Ctrl+P` | 打印 → 选「存为 PDF」，A4 横向，一页一张 |

## 讲之前的三件事

1. **每个数字都能当场复现**——第 24 页列了「数字 → 命令」对照。复现不了的不写。
2. **第 13 页放原始报错，第 18 页列已知边界**，这两页不要跳。删掉它们，前面的数字都会被怀疑。
3. 受众若以**日方**为主，需要另出一版日文——内容同源，术语按对日习惯改写（`内容与中文版一致，术语已按对日项目习惯调整`）。
