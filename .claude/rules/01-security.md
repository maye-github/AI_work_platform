# 01 機密紅線（脱敏と対外持ち出し）

> **このファイルは `plat gate` G6 の走査対象から唯一除外される。**
> 理由：ここは「何を機密と見なすか」の**定義場所**であり、例示のために機密の「形」を書く必要があるため。
> 他のファイルはすべて走査対象である。

---

## 1. 三級区分

| 級 | 定義 | 対外 |
|---|---|---|
| L1 | 公開可 | OK |
| L2 | 要脱敏 | 占位化の上 OK |
| L3 | **禁止外投** | 社内限定。脱敏必須 |

## 2. L3 の 13 項目（形で検出する）

| # | 対象 | 占位 | 備考 |
|---|---|---|---|
| 1 | 接続文字列（ユーザ／ホスト／ポート／SID） | `TBL_1/COL_1@PWD_1:PORT_1/SID_1` | |
| 2 | 認証基盤の設定（ドメイン／Audience） | `DOM_1` ／ `https://AUD_1` | |
| 3 | オブジェクトストレージのバケット名 | `BUCKET_1` | 環境名・案件番号を残さない |
| 4 | クラウドのプロファイル名 | `PROFILE_1` | |
| 5 | 暗号鍵（当日鍵・マスタパス） | `KEY_1` | 日付そのものも残さない |
| 6 | `.env` のパスワード・鍵全般 | `PWD_1` | 変数名は残してよい |
| 7 | 内部セグメント IP | `IP_1`（`IP_1/16`） | RFC1918 |
| 8 | 社内メールアドレス | `MAIL_1` | ローカル部も残さない |
| 9 | DB オブジェクト名（業務固有） | `TBL_1_FNC` | 接頭辞のみは残してよい |
| 10 | 業務データの実値（コード・品番・金額・番号） | `COL_1 = VAL_1` | 型・桁は残してよい |
| 11 | 緊急配信トリガー条件式 | `IF TRG_1 THEN SET X = '9'` | 条件式として書かれた形のみ検出 |
| 12 | 復号関数の実引数 | `TBL_1_FNC(COL_1, PWD_1, KEY_1)` | |
| 13 | 実在の社員コード・氏名 | `EMP_1 = NAME_1` | 特定できる組み合わせを残さない |

## 3. 顧客名の扱い（L3 ではないが L2）

- **内部**（`docs/`・`.claude/`・台帳・traps）：記載してよい。抽象化すると案件が読めなくなる。
- **対外**（対日成果物・報告書・PPT）：`plat mask` で `<客户A>` 形式へ置換してから出す。
- **禁止**：顧客名と実データ値・実 IP・接続情報を**同じ行・同じ表に併記しない**。

## 4. 脱敏の運用

```
plat mask assign --plain "<顧客名>" --code "<客户A>"   # 対照を登録（registry/MASK_MAP.yaml）
plat mask apply --write                                # 成果物の明文を代号へ置換
plat mask check                                        # 残留明文 / 未登録代号を検査（G6 の一部）
plat mask list --safe                                  # 対照一覧（画面共有前に --safe）
```

- `registry/MASK_MAP.yaml` は**それ自体が機密**。`.gitignore` 済み、コミット禁止、外発禁止。
- `raw/`（日方の生資料）も同様。**成果物には代号だけを書く**。
- **工程1 の取込前**：`plat mask prep --module <模块>` を実行し、AI は `requirements/ai_input/` **だけ**を読む。
  `raw/` は AI が直接読まない（`guard_raw` フックが遮断する）。`raw_requirements.md` は脱敏後の正規化ファイルとして例外的に読み書きできる。

## 5. 外に出す前の 3 点チェック

1. `plat gate --only 6` が PASS
2. `plat mask check` が 0 件
3. 対外物に**内部 ID・内部注記・検討メモ**が残っていないこと（例：`ISS` の社内議論、`Q` の社内解釈）

## 6. 機械で捕まえられないもの

- 文脈依存の言い換え（「あの件」「例の会社」など）はパターンで拾えない。**人が読む。**
- 顧客名と実データの**組み合わせ**による特定。単体では L2 でも、並ぶと L3 になる。
